# 群组管家 v6.3（Cloudflare Workers）

群组管家 Bot：**私聊**向我发起所有操作，发布到你选择的群。
内置**抽奖**、**入群验证**、**管理员公告**、**群投票**、**群管工具**五大模块，并支持**默认群/频道**与**时区**设置。

## 功能

### 🏠 主菜单（/start 内联键盘）
发送 `/start` 弹出内联键盘菜单：
- ✨ 创建抽奖 · 📢 发布公告 · 📊 发起投票 · 📋 我的抽奖
- ⚙️ **设置群组**：列出 bot 已加入的群，点选设为**默认发布群**（⭐ 标记）
- ⚙️ **设置频道**：列出 bot 已加入的频道，点选设为**默认发布频道**
- 🌏 **设置时区**：北京时间 (UTC+8，默认) / 东京 (UTC+9) / 曼谷 (UTC+7) / UTC / 纽约 (UTC-5)

### 🎁 抽奖模块
- 📝 **私聊创建向导**（共 8 步）：活动名称 → 奖品 → 中奖名额 → 口令 → 开奖方式 → 开奖条件 → 选择发布群 → 频道(可选)
- ⏱️ **快捷开奖时间**：点选「10分钟后 / 1小时后 / 1天后 / 1周后」按钮，或输入 `10分钟后`、`1天后` 等相对时间，也可输入具体时间 `2026-08-25 20:00`，自动换算成**当前时区**日期显示
- 📢 **发布到群 + 频道，自动置顶**：创建完成后公告自动发到选定群并 **pin 置顶**；开奖/取消时自动取消置顶
- 🔑 **口令参与**：参与者在群内发送口令即参与
- ⏰ **定时开奖**（Cron 每分钟检查）/ 👥 **人数开奖**（满员自动开）
- 📣 **强制加频道**：可要求先加入指定频道才能参与
- 🥳 **开奖通知**：群内公告 + 私信中奖者 + 私信创建者中奖名单

### 🛡️ 入群验证模块
- 新成员加入时自动**禁言**并发送验证按钮，点击后解除禁言并欢迎入群
- 10 分钟未验证自动**移出群聊**（bot 需为群管理员）
- 按群开关：管理员在**群内**发送 `/verify on|off` 控制

### 📢 管理员公告模块（私聊发起，交互式）
- 私聊发送 `/announce` → 机器人提示输入内容 → 发送内容 → 列出已加入群 → **点选目标群** → bot 发布公告并**自动置顶**
- 自动校验你是否是目标群管理员；不是则拒绝
- 也可在选群时手动输入群 ID（负整数，如 `-1001234567890`）
- 草稿有效期 15 分钟，超时需重新发送

### 📊 投票模块（私聊发起，交互式）
- 私聊发送 `/poll` → 机器人提示输入内容 → 发送 `问题|选项1|选项2|...` → 列出已加入群 → **点选目标群** → bot 在群里发原生匿名投票
- 多选：`--multi 喜欢哪些？|A|B|C`（可跟在内容前一起发送）
- 支持全角 `｜` 和半角 `|`，最多 10 个选项，问题 ≤300 字，选项 ≤100 字

### 📋 其他
- `/list` 查看我创建的抽奖 · `/draw <ID>` 手动开奖 · `/cancel <ID>` 取消
- `/groups` 查看 bot 已加入的群

### 🛠️ 群管工具（群内命令，管理员可用）
| 命令 | 说明 |
|------|------|
| `/mute 1h` | 🔇 禁言：**回复**目标消息 + `/mute 30s|5m|1h|1d|forever`（forever 为永久） |
| `/unmute` | 🔊 解除禁言：回复目标消息 |
| `/kick` | 👢 踢出：回复目标消息 |
| `/ban` | 🚫 封禁：回复目标消息 |
| `/unban` | ✅ 解封：回复目标消息 |
| `/warn [原因]` | ⚠️ 警告：回复目标消息；满 3 次自动移出 |
| `/unwarn` | ↩️ 撤销警告：回复目标消息 |
| `/warns` | 📋 查看该成员警告次数：回复目标消息 |
| `/rules` | 📜 查看群规；`/rules 文本` 设置（管理员） |
| `/welcome` | 👋 查看欢迎语；`/welcome 文本` 设置（管理员，含抽取变量） |
| `/admins` | 🛡️ 管理员列表 |
| `/info` | ℹ️ 群信息（群名/成员数/管理员/ID/bot 权限） |
| `/settitle 新标题` | ✏️ 修改群标题（管理员） |

> 群管命令全部要求：**回复**一条目标消息（mute/kick/ban/warn 等），且执行者是群管理员，否则拒绝。

## 使用流程

**公告：**
```
私聊 bot → /announce
  ↓
bot：请发送公告内容
  ↓ 发送内容
bot：选择发布群（按钮）→ 点击目标群
  ↓
bot 校验管理员 → 发布公告并置顶 → 私聊通知成功
```

**投票：**
```
私聊 bot → /poll
  ↓
bot：请发送 问题|选项1|选项2
  ↓ 发送内容
bot：选择发布群（按钮）→ 点击目标群
  ↓
投票发布到目标群 → 私聊通知成功
```

**抽奖开奖时间：**
```
第5步选择「⏰ 定时开奖」→ 出现快捷按钮
  ⏱️ 10分钟后 / ⏱️ 1小时后 / ⏱️ 1天后 / ⏱️ 1周后
  ↓ 点击或输入相对时间 / 具体时间
自动换算为日期显示（如 2026-08-20 15:30）→ 第6步选群
```

## 部署

### 1. 准备工作

1. `@BotFather` 创建机器人，拿到 `BOT_TOKEN`
2. 把机器人加到你想要发布抽奖的群组，并设为**管理员**（入群验证/置顶/踢人都需要）
3. 把机器人加为频道**管理员**（若要发布到频道/强制加频道）
4. Cloudflare 创建 KV Namespace，记录 Namespace ID

### 2. 配置 wrangler.toml

把 KV ID 填入：

```toml
[[kv_namespaces]]
binding = "LOTTERY_KV"
id = "你的KV_NAMESPACE_ID"
preview_id = "你的KV_NAMESPACE_ID"
```

Cron 触发器已声明（`crons = ["* * * * *"]`），部署时自动创建，用于定时开奖 + 入群验证超时检查。

### 3. 设置 Cloudflare Worker Secrets

在 Cloudflare Dashboard → Worker → Settings → Variables：

| 变量 | 值 |
|------|-----|
| `BOT_TOKEN` | BotFather 给的 Token（**Secret**） |
| `WEBHOOK_SECRET` | 任意随机字符串（**Secret**，可选） |

### 4. GitHub Actions 一键部署

- GitHub Secrets 只填两个：`CF_API_TOKEN`（Workers Edit + KV Edit 权限）、`CF_ACCOUNT_ID`
- push 到 main 自动部署

### 5. 设置 Webhook

```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<你的worker域名>/webhook"
```

或使用 `scripts/setWebhook.mjs`（已包含 `chat_member` 更新，入群验证必需）。

> ⚠️ 升级自 v6.0 时：部署后请重新设置一次 Webhook；命令菜单 v6 标记会自动刷新一次。
